# UpDish Demo 시연 순서

해커톤 모의 투자입니다. 아이디어 발표와 별도로 아래 하나의 흐름을 보여줍니다. 실제 자금 이동은 없고, GIWA 거래는 사용자 지갑이 직접 승인합니다.

1. 지갑 연결·SIWE 로그인 → 첫 화면 ‘가게 목록’. 성수 모퉁이를 열어 매출 차트·계약·위험을 확인합니다.
2. ‘결제·정산 대조로 운영 투명성 확인’ → POS 고객 결제, PG 정산, 은행 입금을 비교합니다. 정상 자료와 망원 은행 누락, 합정 PG 불일치, 을지로 환불 정정을 보여줍니다. 가상 CSV와 승인 원장을 구분합니다. 누락은 자료 없음이며 승인 차단입니다.
3. 가게 상세 → 청약하기 팝업 → 100단위·100만원 예시·필수 동의 → 접수. 투자 내역의 청약 탭에서 확인하고 배정 전 취소도 가능합니다.
4. 운영자 ‘시연 준비’에서 배경 3,500단위를 준비하고 배정합니다. 청약 접수와 배정된 보유를 구분합니다.
5. 가게 담당자는 ‘가게 관리’ → 매출 CSV 제출 팝업에서 정상 자료를 제출합니다. 다른 검토 지갑이 자료 검토 → 대조 상세 → 사유 → 마감합니다. 은행 누락/PG 불일치는 마감할 수 없습니다.
6. 검토 지갑이 정산을 산정하고 다른 승인 지갑이 운영 관리 → 정산·지급 → 선택 정산 관리 팝업에서 승인합니다. 정상 3,000만원 × 3% = 90만원, 100 / 3,600단위의 세전 의무액은 25,000원입니다. 지급 실패·부분 지급·정정은 별도 이력입니다.
7. 투자 지갑으로 투자 내역 → 정산 근거 팝업에서 본인의 금액·지급·미지급을 확인합니다. 승인 원장은 운영 투명성에도 반영됩니다. 제출 중인 금액과 고객 거래 원본은 공개하지 않습니다.
8. 상단 Agent → 일반 채팅으로 가게 대조를 질문합니다. 투자 내역의 ‘Agent에게 질문’은 해당 본인 정산을 선택합니다. 주제·메시지·입력창을 중심으로 사용하며 근거는 접혀 있습니다. 데스크톱은 본문과 나란한 사이드바, 모바일은 전체 화면 채팅입니다.

고객 전용 화면과 쿠폰 발급은 제거했습니다. 운영자/가게/투자자 관점 전환은 설명용이며 실제 권한을 바꾸지 않습니다. 여섯 가상 계정 예시는 읽기 전용입니다. 상단 ‘시연 순서’는 화면만 이동하고 거래·승인·지급을 실행하지 않습니다.

## 실행과 실제 연결

공개 주소는 [배포 웹](https://updish-hackathon-20261025-betaplayers-projects.vercel.app/)입니다. 로컬 피드백은 `http://127.0.0.1:3000/`을 사용합니다. 정확한 배포 버전은 [릴리스 기록](evidence/transparency-agent/release.json)에 있습니다.

Vercel Web → EC2 Spring → 내부 FastAPI → OpenAI(gpt-5-mini)입니다. 모델 키는 ignored 로컬 `.env.local`과 EC2의 0600 환경 파일에만 저장합니다. 키를 Web/NEXT_PUBLIC/Git에 넣지 않습니다. 실패하면 실제 오류를 표시하고 답변이나 지급 성공을 꾸미지 않습니다. 모델은 읽기 전용이며 업무/지갑 거래를 실행하지 않습니다. 답변과 원장 수치를 함께 확인합니다.

DB는 EC2 PostgreSQL 18.6이며 Supabase는 미사용입니다. 2026-10-26 실측 약 9MB, PostgreSQL 약 72MiB, EC2 사용 가능 메모리 약 2.8GiB입니다. DB를 외부로 옮기는 것만으로 EC2 인스턴스 요금은 감소하지 않습니다. 이전과 서버 축소는 별도 검토합니다.

검증 자료: [브라우저](evidence/transparency-agent/browser-local.json), [최종 렌더링](evidence/transparency-agent/browser-final.json), [로컬 개인 정산 실제 모델](evidence/transparency-agent/model-private-local.json), [업무 E2E](evidence/business-local-e2e.json). 업무 자동 검사는 별도 DB·Anvil·테스트 지갑이며 사용자 GIWA 거래가 아닙니다. Bojagi, Reown QR ID, 실제 지갑 계약/mint/registry·철회 시연은 기존 후속 이슈를 따릅니다.
